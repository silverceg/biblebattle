# 성경 배틀 아레나 v8.1 — 공격 버튼 서바이벌

50~60명이 각자 만든 캐릭터로 광야를 돌아다니며 성경 퀴즈로 싸우는 실시간 서바이벌 게임입니다.
체력이 있고, 적 가까이에서 **⚔ 공격 버튼**을 누르면 **내 폰에만 문제**가 나오고, **맞히는 순간 바로 피해**가 들어갑니다. 마지막까지 살아남은 한 사람(한 팀)이 우승합니다.
메인 화면은 중계 방송처럼, 참가자는 스마트폰(가로)으로 플레이합니다.

---

## 📂 파일 구성 — 이 구조 그대로

```
성경픽셀배틀\
├─ server.js               게임 서버
├─ questions.json          성경 퀴즈 281문제 (구약·신약·인물·넌센스)
├─ package.json            설치 정보
├─ sim.js                  밸런스 시험용 봇 시뮬레이터 (선택)
├─ load.js                 60명 부하 테스트 (선택)
├─ README.md               이 설명서
├─ 지형_미리보기.png · 캐릭터_미리보기.png · 상자_보스_미리보기.png
├─ 실행하기(윈도우).bat     ← 평소엔 이걸 더블클릭
├─ 공개주소로_켜기(윈도우).bat  ← 외부 사람도 참여시킬 때
├─ 실행하기(맥).command
├─ .gitignore              클라우드에 올릴 때 제외 목록
├─ node_modules\           npm install 또는 node_modules.zip 을 풀어서
└─ public\                 ← 이 안에 네 개가 모두 있어야 합니다
   ├─ host.html · index.html · sprite.js · audio.js
   └─ music\               ← 내 mp3 넣는 곳 (안내 파일 참고)
```

**첫 실행만** `npm install`. 인터넷이 막혀 있으면 이전에 드린 `node_modules.zip`을 폴더에 풀면 됩니다.
파일을 덮어쓴 뒤에는 서버를 껐다 켜고 화면을 새로고침하세요 (v8은 화면 파일 버전이 바뀌어 자동으로 새 파일을 받습니다).

| 어디에 | 주소 |
|---|---|
| 메인 화면 | `http://localhost:3001/host` |
| 학생 폰 | **메인 화면에 뜨는 QR·주소** (메인 화면을 연 주소를 그대로 따릅니다) |

QR과 접속 주소는 **메인 화면을 어떤 주소로 열었느냐**를 따라갑니다. 와이파이 안에서 `192.168.…`로 열면 그 주소가, 외부 서버·터널 주소로 열면 그 주소가 뜹니다. `localhost`로 열었을 때만 와이파이 주소로 바꿔 보여 줍니다. 외부 주소로 열 때는 **메인 화면도 그 외부 주소로 여세요** (예: `https://….loca.lt/host`).

## 🌐 다른 곳에 있는 사람도 참여시키기

### 방법 A — 지금 이 컴퓨터를 임시로 공개 (행사 당일용, 5분)
`공개주소로_켜기(윈도우).bat` 을 더블클릭하면 서버가 켜지고, 잠시 뒤 검은 창에 `https://xxxx-xxxx.loca.lt` 같은 **인터넷 어디서나 열리는 임시 주소**가 나옵니다.
1. 그 주소 뒤에 `/host` 를 붙여 메인 화면을 엽니다 → QR이 자동으로 그 주소로 바뀝니다
2. 학생들은 QR을 찍으면 됩니다. 처음 열 때 "Click to Continue" 확인 화면이 한 번 뜰 수 있습니다 — 눌러 주면 됩니다
3. 창을 닫으면 주소가 사라집니다. 매번 새 주소가 나옵니다

(더 안정적인 무료 터널: Cloudflare Tunnel `cloudflared tunnel --url http://localhost:3001` — 프로그램을 따로 받아야 합니다)

### 방법 B — 클라우드 서버에 올려두기 (Render 무료)
1. GitHub 저장소에 이 폴더의 파일을 올립니다 (`node_modules` 는 올리지 않습니다 — `.gitignore` 에 이미 빠져 있습니다)
2. render.com → **New → Web Service** → 그 저장소 선택
3. Runtime **Node**, Build `npm install`, Start `node server.js`, Instance **Free**
4. 메인 화면은 `https://이름.onrender.com/host`

알아두실 점:
- 무료 서버는 15분 동안 아무도 안 쓰면 잠들었다가 첫 접속 때 30초쯤 걸려 깨어납니다. **행사 10분 전에 메인 화면을 먼저 열어 두세요**
- 결과 CSV·누적 기록은 서버 안에 저장되는데, 무료 서버는 재시작하면 파일이 지워집니다
- `PORT` 환경변수를 서버가 자동으로 읽습니다 (Railway, Fly.io 도 같은 방식)

### v8.1 — 주일 전 점검에서 고친 것
- **나무 상자 카드가 두 번 뜨던 문제**: 카드를 고른 직후 늦게 도착한 정보 때문에 같은 카드 묶음이 다시 뜨던 것을 막았습니다. 두 번 눌러도 한 번만 적용됩니다
- **관전 화면이 폰보다 늦던 문제**: 관전 화면이 받은 정보를 쌓아 두지 않고 늘 최신 것만 그리게 바꿨고, 매 순간 화면 배치를 다시 계산하던 부분(순위표·공격 목록·시계 글자)을 바뀔 때만 고치게 했습니다. 느린 노트북을 흉내 낸 시험에서 초당 2~3장 → 17~24장, 지연 0.5~1.3초(점점 늘어남) → 0.1초 안팎. 그래도 버거우면 스스로 **가벼운 모드**로 바뀝니다
- 관전 화면은 1초에 20번 정보를 받고(예전 12번), 서버 시각 기준으로 부드럽게 그립니다. 상자·명중 연출도 바로바로 옵니다
- **두 손가락 조작**: 왼손으로 조이스틱을 누른 채 오른손으로 공격·회피·궁극기·보기·카드를 누르면 안 눌리던 문제를 고쳤습니다 (손가락이 닿는 순간 반응)
- 잠깐 끊겼다 돌아온 폰이 지난 문제 창이나 지난 판 결과 화면에 갇히지 않게 했습니다. 늦게 끊긴 옛 연결이 학생을 '끊김'으로 바꾸던 문제도 고쳤습니다
- 팀원 살리기 문제를 푸는 동안에는 22초 제한이 멈춥니다 · 멈춤 중에 마지막 한 명이 남으면 다시 시작할 때 바로 우승 처리 · 쓰러져 있는 동안 카드가 저절로 골라지지 않음 · 느부갓네살이 자물쇠 퀴즈 중인 상자는 안 부숨
- 혼자(또는 한 팀만) 시험할 때 최후의 심판이 끝나지 않던 문제 → 바로 우승으로 끝납니다
- 이상한 신호가 와도 서버가 멈추지 않게 안전장치를 넣었습니다
- 서버가 버거워하면 관전 화면 위에 **⚠ 서버가 버거워해요** 띠가 뜹니다 (아래 '안 될 때' 참고)

## ⚔ 공격 버튼 전투

- 적이 **약 4칸 안**에 들어오면 폰 오른쪽 아래 빨간 **⚔ 공격** 버튼이 켜지고, 버튼에 노릴 상대 이름이 뜹니다 (가까운 사람 → 보스 → 미니언 순서). 컴퓨터로 해 볼 땐 스페이스바
- 누르면 **내 폰에만 문제**가 나옵니다: 8초 + 긴 문제는 최대 4초 더. 문제를 푸는 동안 **나는 서 있고, 상대는 계속 움직입니다**
- **맞히는 순간 바로 피해** = 내 공격력 × 배율. **4초 안에 맞히면 ×1.2** (빠른 손 카드는 ×1.5)
- 맞혔는데 그사이 상대가 **10칸 넘게 도망갔으면 놓칩니다**. 회피 중·무적이면 무효, 믿음의 방패는 한 번 막음
- 틀리거나 시간이 지나면 2.5초 쉬고, 맞히면 1.2초 뒤 다시 공격할 수 있습니다
- **노려지는 쪽**: 폰에 빨간 **"○○이(가) 나를 노린다!"** 경고 + 진동 → 멀리 도망 · ↯ 회피(3초 동안 아무도 못 맞힘) · 아니면 서 있는 공격자를 맞서 공격
- **기습**: 수풀에 숨으면 아주 가까이(2칸) 와야 보이고, **숨은 채로 공격하면 경고가 안 뜨고 피해 1.5배**
- **한 방 상한**: 한 번에 최대 체력의 **35%**까지만 깎입니다 (한 방에 끝나지 않게). 홍수가 깊어질수록 상한도 커져 마지막엔 약 52%. 궁극기 명중은 55%부터 (마지막엔 70%)
- **다윗과 골리앗**: 나보다 레벨이 높은 상대를 때리면 레벨 차 1당 +8% (최대 +40%). 3레벨 이상 높은 상대를 쓰러뜨리면 칭호 🎯
- 연결이 잠깐 끊긴 친구는 20초 동안 공격받지 않습니다

## 🌱 → 🌊 → ⚖ 세 단계

### 🌱 성장 (게임 시간 앞 절반)
- 쓰러져도 폰에 나오는 **문제 2개를 맞히면 체력 60%로 부활** (최소 4초). 틀려도 다음 문제가 나옵니다
- 이때 미니언·상자·보스로 레벨을 올려 두세요
- 홍수 30초 전에 경고가 뜹니다

### 🌊 홍수 (게임 시간 뒤 절반) — 이제 쓰러지면 탈락
가장자리부터 물이 차오르고, **물속에 있으면 체력이 깎입니다.** 메인 화면에 **흰 점선 원 = 다음 안전지대**가 미리 보입니다. 폰에도 화살표로 안전지대 방향이 나옵니다.

| 물결 | 시작 (10분 게임 기준) | 안전지대 | 물속 피해 | 공격 피해 |
|---|---|---|---|---|
| 1 | 5:00 지남 | 지도의 55% | 초당 3% | ×1.2 |
| 2 | 6:36 지남 | 30% | 초당 5% | ×1.4 |
| 3 ⛵ 방주 | 8:06 지남 | 13% | 초당 8% | ×1.7 |
| 4 ⛵ 방주 | 9:18 지남 | 6% | 초당 12% | ×2.0 |

- 3번째 물결부터는 **방주** — 보스와 미니언이 사라지고 살아남은 사람끼리만 남습니다
- 물에 잠긴 상자·미니언·보스는 사라지고, **건너편이 물에 잠긴 포탈은 작동하지 않습니다**
- 문제를 푸는 동안에는 물 피해를 받지 않습니다 (문제에 집중하도록)

### ⚖ 최후의 심판 (시간이 다 됐는데 2명 이상 남았을 때)
- 남은 사람 **모두 같은 문제** (14초 + 문제 길이). 메인 화면에 문제와 전원의 제출 상황이 크게 뜹니다
- **틀리면 탈락.** 모두 틀리면 아무도 탈락하지 않습니다
- **2라운드부터는 맞힌 사람 중 가장 늦게 맞힌 사람도 탈락** — 빠르고 정확하게!
- 10라운드까지 안 갈리면 체력 비율이 가장 높은 사람이 우승
- **팀전 심판은 3라운드**: 틀린 사람만 탈락하고, 3라운드가 끝나면 **더 많이 살아남은 팀**이 우승 (같으면 체력이 더 많은 팀)

## 🤝 팀전 서바이벌 (2팀 · 4팀)

- 대기실에서 **팀 다시 섞기**로 나눈 팀이 그대로 시작합니다 (인원이 어긋났을 때만 자동으로 다시 나눔)
- 성장 단계는 개인전과 같습니다 (문제 2개로 부활)
- 홍수 단계에서 쓰러지면 **22초 동안 🆘** — 팀원이 곁에 가면 문제가 나오고, 맞히면 **체력 40%로 일으킵니다.** 🎵 수금 궁극기로도 일으킬 수 있습니다
- 팀원이 살려 주는 기회는 **한 사람당 한 번** — 두 번째로 쓰러지면 바로 탈락합니다 (폰에 경고가 뜹니다)
- 22초가 지나거나 살아 있는 팀원이 없으면 탈락. **마지막까지 살아남은 팀이 우승**
- 메인 화면 오른쪽 위에 팀별 생존 인원·처치 수, 전멸한 팀은 회색으로 순위와 함께 표시

## 🎯 지물별 궁극기 — 일발 역전

캐릭터를 만들 때 고르는 **지물**이 늘 붙는 특성과 궁극기를 정합니다. 궁극기는 **시작 1분 뒤 준비**되고, **한 번 쓰면 1분 뒤** 다시 채워집니다. 폰 오른쪽 아래 **금색 버튼**이 빛나면 쓸 수 있습니다.

| 지물 | 늘 붙는 특성 | 궁극기 |
|---|---|---|
| 물맷돌 | 이동 속도 +12% | 🎯 **다윗의 물맷돌** — 30초 안의 다음 공격을 맞히면 피해 2배. 상대 레벨이 높을수록 더 세짐 (레벨 차 1당 +15%, 최대 +75%) |
| 방패 | 처음 두 번 받는 피해 절반 | 🛡 **믿음의 방패** — 체력 25% 회복 + 25초 안에 받는 공격 한 번을 막음 |
| 두루마리 | 문제 푸는 시간 +4초 | 📜 **말씀 선포** — 주변 적(최대 6명) 모두에게 문제. 틀린 사람은 모두 피해 |
| 등불 | 문제마다 25% 확률로 오답 삭제 | 🕯 **지혜의 빛** — 45초 동안 다음 문제 3번, 오답 2개 삭제 |
| 지팡이 | ↯ 회피를 더 자주 (40초 → 24초마다) | 🌊 **홍해 가르기** — 주변 적을 밀어내고 8초 무적 + 빠른 이동 (물 피해도 없음) |
| 수금 | 자연 회복 2배 | 🎵 **다윗의 수금** — 체력 45% 회복. 팀전이면 주변 팀원 25% 회복 + 쓰러진 팀원 일으키기 |

- **뒤처진 친구(레벨 하위 40%)는 궁극기가 25% 빨리** 찹니다
- ⚡ 준비된 마음 카드 한 장마다 −10초 · ☠ 보스를 이기면 **즉시 충전**
- 궁극기를 쓰면 메인 화면에 **컷인**(이름·궁극기 이름이 화면을 가로지름)과 파동이 나옵니다

## 🖥 메인 화면 (선생님)

**진행 순서**: 오프닝 클릭 → 대기실 → 문제집·모드·시간 고르기 → **게임 시작** → 엔딩 → 결과 → **대기실로**

- **위쪽 막대**: 남은 시간 · **단계 표시**(🌱 성장 / 🌊 홍수 n단계 / ⛵ 방주 / ⚖ 최후의 심판) · **생존 n/전체** · 진행 중인 공격 · 문제 사용
- **지도**: 파란 물과 물결, 흰 점선 = 다음 안전지대, 캐릭터 머리 위 **체력바**와 레벨, 발밑 ⚔처치 수, 🆘(팀원을 기다림) 남은 초. **공격 중이면 공격자 → 표적 빨간 점선 + 표적 위에 돌아가는 과녁 + 남은 초**, 명중하면 빛이 날아가 터지고 피해 숫자. 궁극기 발동 컷인, 쓰러짐·탈락·부활(빛기둥)·기도(비둘기) 연출
- 가운데 위 **홍수 알림 띠**: "홍수까지 0:45", "물이 차오릅니다!", "다음 홍수까지 1:20"
- **방주 카메라**: 물이 차올라 안전지대가 좁아지면 화면이 자동으로 안전지대를 크게 비춥니다 (오른쪽 위 작은 지도에 전체가 보임). 선수를 누르거나 공격을 중계하면 그쪽이 먼저입니다
- **오른쪽 순위표**: 살아 있는 사람(처치 수·레벨·체력 순, 체력바 포함) → 탈락한 사람(흐리게, 탈락 순위 표시)
- **선생님 도움**: 순위표에서 이름을 누르면 버튼이 나옵니다 — 살아 있으면 **❤ 회복**(30%), 탈락했으면 **✨ 부활**(연결이 끊겨 억울하게 떨어졌을 때)
- **공격 중계**: 오른쪽 "진행 중인 공격" 목록이나 지도 속 캐릭터를 누르면 크게 중계 — 문제와 보기, 공격하는 사람(고민 중… / 제출)과 표적(🏃 노려지는 중!), 끝나면 정답·명중·놓침·회피가 공개됩니다. 🎥 자동 중계를 켜면 쓰러질 것 같은 공격·현상금·보스·막판 공격을 알아서 비추고, 결과를 3초쯤 보여 준 뒤 다음으로 넘어갑니다
- **최후의 심판**: 문제와 남은 사람 전원의 얼굴이 크게 뜨고, 제출 ✔ → 통과 / 탈락이 한꺼번에 공개됩니다
- **엔딩**: 🏆 최후의 1인 배너 → 3·2·1위가 시상대로 걸어 들어옴 → 순위·부문상·많이 틀린 문제 TOP 5
- 단축키: `F` 전체화면 · `Esc` 전체 보기 · `P` 성능 표시 · 대기실에서 `← →` 안내 넘기기

대기실 왼쪽 **안내 슬라이드 8장**이 규칙을 자동으로 설명합니다 (공격 버튼 · 세 단계 · 강화 카드 · 궁극기 6종 · 팀전과 중보기도 · 보스·미니언 · 상자 카드 · 현상금).

## 🔧 기술
입력 번호 기반 예측·보정 이동(서버가 알려 주는 실제 속도로 예측 — 날쌘 발 카드·아이템에도 어긋나지 않음) · 다른 사람은 서버 시각 기준 보간(폰 140ms · 관전 화면 80ms) · 가만히 있을 땐 입력을 보내지 않음 · 일시정지하면 게임 시계 자체가 멈춤(홍수·부활·궁극기 시간도 함께) · 모든 응답 no-store · 오류 띠는 진짜 오류일 때만.

### ✨ 선명한 캐릭터 렌더링
- **정수 배율로만 확대** — 1배 도트 그림을 기기 픽셀 기준 2배·3배·4배로만 찍어 픽셀이 들쭉날쭉하지 않습니다
- **폰은 실제 해상도로** (절전 모드 1배, 계속 버벅이면 자동으로 2배)
- **관전 화면도 고해상도 모니터 대응** (125%·150%, 레티나, 4K TV)
- 지형·상자 이음매 없음 · 작은 아이콘은 전신·상반신·얼굴로 잘라 또렷하게

## ❓ 안 될 때

| `npm install` 멈춤 | `node_modules.zip` 을 폴더에 풀기 |

| 새 파일을 올린 뒤 이상함 | Render가 다시 켜지는 동안(1~3분) 기다린 뒤 **관전 화면을 새로고침**(Ctrl+Shift+R). 학생들도 새로고침 |
